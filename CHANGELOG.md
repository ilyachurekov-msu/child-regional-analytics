# Изменения

## 0.1.0 — техническая приёмка, 2026-11-24 (не готовый релиз)

- Отдельная ветка и новый публичный репозиторий по просьбе пользователя; старые репозитории не изменяются.
- Аудит критериев MVP, честный статус реальных данных и межмодульных контрактов.
- Миграция 0002: происхождение оригиналов, неизвестная дата публикации NULL.
- ETL: сверка единиц, предварительный статус, отклонение старых публикаций до проверки равенства значений.
- Специализированный строгий PDF-адаптер Липецкстата; manifest, контролируемое обновление и отчёт. До проверки оригинала адаптер выключен.
- GitHub Actions: обязательные PostgreSQL и Docker проверки, Playwright/артефакты, секреты/зависимости; отдельная проверка источника без расписания.
- Кандидат пакета shared-contracts без изменения существующих ID. Общая совместимость пока не утверждена.

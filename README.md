## Для пользователя: что уже можно делать

Система показывает годовые показатели рождаемости, смертности, естественного прироста, браков и разводов по регионам, когда загружены официальные наблюдения. Выберите раздел слева: паспорт региона, сравнение от двух до пяти регионов или динамику. В разделе экспорта выберите регион и скачайте справку, CSV или Excel. Источник, период и единица указываются рядом с данными. Если наблюдений нет, система сообщает об этом — цифры не придумываются.

Абсолютные числа зависят от размера региона. Они не показывают индивидуальный риск и не означают готовую оценку благополучия детей. РФ и федеральные округа отображаются только по опубликованным агрегатам. Пропуски не равны нулю. Исследовательский индекс требует отдельно выбранных весов и направлений; официальным индексом он не является.

## Проверки без установки Docker Desktop

Автоматические проверки подготовлены в GitHub Actions: при каждом PR отдельно запускаются unit-тесты, настоящая PostgreSQL 16, Docker, Streamlit, Chromium со скриншотами, контроль контрактов, секретов и зависимостей. Результаты видны во вкладке Actions репозитория, логи и скриншоты — в артефактах запуска. Пока workflow не исполнен успешно, его наличие не доказывает работоспособность Docker или PostgreSQL. Постоянный публичный сервер не создаётся.

Обновление статистики контролируемое: workflow Controlled source check запускается вручную, регулярного расписания нет. Он проверяет исходный PDF и не публикует оригинал. Специализированный адаптер пока выключен до сверки фактического файла. Подробности: [источники](docs/data-sources.md), [развёртывание и CI](docs/deployment.md).

## Необязательный локальный запуск через Docker

Если Docker уже доступен и нужен локальный запуск, из корня проекта в PowerShell (установка Docker Desktop не требуется для CI-приёмки):

```powershell
Copy-Item .env.example .env
# Задайте свой POSTGRES_PASSWORD и тот же пароль в DATABASE_URL файла .env.
docker compose up --build -d
docker compose logs init
```

Интерфейс: http://localhost:8501 · API/OpenAPI: http://localhost:8000/api/v1/docs.
Сервис `init` применяет миграции, справочники и проверенную официальную выборку перед запуском API. Выберите «Кемеровская область — Кузбасс», чтобы увидеть реальные ряды; остальные субъекты пока без официальных значений. Исходный HTML в Git не включён, опубликован только числовой поднабор с атрибуцией. Данные PostgreSQL сохраняются в томе `postgres_data`. Остановка: `docker compose down` (без `-v`, чтобы сохранить БД).

## Получение и загрузка данных

```powershell
docker compose exec api python -m scripts.fetch_rosstat
```

Команда сохраняет исходную страницу, доступные XLSX и отчёт о скачивании. Загрузка из интернета не запускается при открытии интерфейса. Для альтернативной публикации подготовлен адаптер: `python -m scripts.update_data --source lipetsk-edn-2023 --validate-only`. Он проверяет структуру и естественную убыль. При недоступном источнике контролируемо завершается ошибкой. Пользователю не нужно вручную перепечатывать таблицы; для законно скачанного оригинала поддерживается `--file`. Подробности в [журнале источников](docs/data-sources.md).

Нормализованный CSV UTF-8 / XLSX / JSON содержит поля:

```text
indicator_code,region,period_start,period_end,value,published_at
```

`region` — `RU-77` либо однозначное название из справочника; `period_start/end` — полный календарный год ISO; `value` — опубликованное число либо пустая ячейка; `published_at` — дата публикации ISO с часовым поясом или пустая ячейка, если неизвестна. Не подменяйте её датой загрузки. Необязательные `unit` и `data_status` позволяют проверять единицы и предварительный статус. В CSV десятичную запятую заключайте в кавычки. Коды показателей: `births`, `deaths`, `natural_change`, `marriages`, `divorces`. Не вставляйте отсутствующие сведения как нули. Шаблон без значений: `contracts/import_template.csv`.

```powershell
docker compose exec api python -m scripts.import_data data/normalized.csv --source-url https://rosstat.gov.ru/compendium/document/13269 --source-name "Росстат: естественное движение населения"
```

Для ряда одного бюллетеня используйте один и тот же URL источника; разные URL обозначают разные источники. Публикации сохраняются версиями, одинаковое содержимое повторно не импортируется. Импорт поддерживает частичную загрузку корректных строк; остальные фиксируются в журнале. Исходный файл хранится по SHA-256. Сохраняйте оригинальную публикацию наряду с нормализованным файлом.

## Разработка без Docker

Нужны Python и отдельный PostgreSQL 16. В `.env` задайте `DATABASE_URL` с хостом `localhost`, `API_URL=http://localhost:8000`.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
alembic upgrade head
python -m scripts.seed
python -m scripts.load_official_bundle
uvicorn app.api.main:app --host 127.0.0.1 --port 8000
# Во втором терминале, с активной той же средой:
streamlit run app/ui/main.py
```

```powershell
python -m pytest -q
```

Тесты используют изолированную SQLite только для проверки логики, импортов и API; она не заменяет PostgreSQL в эксплуатации. Искусственные значения существуют только во временных тестовых файлах, никогда не попадают в пользовательскую БД. Интеграционная проверка PostgreSQL: `docs/testing.md`.

## Структура и эксплуатация

- `app/models`, `migrations` — схема, ограничения, история миграций.
- `app/etl` — проверка, архив, нормализация, версии, журнал ошибок.
- `app/api`, `app/schemas` — API `/api/v1/`, схемы, ошибки, пагинация.
- `app/services`, `app/ui` — аналитика, экспорт, семь разделов интерфейса.
- `contracts` — общий контракт 1.0.0, справочники, шаблон импорта.
- `docs` — архитектура, источники, интеграция, тестирование, отчёт.

Порты привязаны к localhost. Импорт выполняется локальной CLI, публичного API записи нет. Секреты только в окружении. Не передавайте этому модулю персональные и закрытые данные. Перед внешним развёртыванием нужны аутентификация, HTTPS, резервное копирование и ограничения ресурсов. Для автономной работы после импорта интернет не требуется; карта требует локальный проверенный GeoJSON.

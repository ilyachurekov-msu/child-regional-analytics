# Проверки

`python -m pytest -q` проверяет временную тестовую БД, не трогая эксплуатационные данные. `tests/conftest.py` включает foreign_keys SQLite. Проверяются дедупликация файлов, ревизии и единственная текущая версия, пропуски, некорректные значения, сопоставление неизвестных регионов, пагинация и валидация API, сравнение, профили, экспорт CSV/XLSX и защита от формул. Это искусственные тестовые значения, не официальный набор.

После установки Docker:

```powershell
docker compose config --quiet
docker compose up --build -d
docker compose exec api alembic current
Invoke-RestMethod http://localhost:8000/api/v1/health
Invoke-RestMethod http://localhost:8000/api/v1/regions
```

Проверьте загрузку одного реального нормализованного файла дважды: число наблюдений и batch_id должны сохраниться. Исправьте опубликованное значение в новом файле с корректной датой: запрос `history=true` должен показать обе ревизии, обычный запрос только новую. Повторите параллельно два импорта, убедитесь в отсутствии дубликатов. Это отдельная обязательная PostgreSQL-проверка, SQLite не проверяет advisory locks и TIMESTAMPTZ.

Откройте семь разделов UI; проверьте отсутствие ошибок, пустое состояние, график двух регионов за два года, ссылки источников и выгрузку. Для карты нужен проверенный GeoJSON со стабильными properties.region_id и документированной лицензией. Тест офлайн: после импорта отключите доступ в интернет, API, таблицы, графики и экспорт должны работать.

# Контракт интеграции 1.0.0

Общие сущности описаны в `contracts/platform.schema.json`, версия фиксирована `1.0.0`. Назначенный этой разработкой справочник `regions.csv` должен быть принят другими модулями: независимые уже существующие ID нельзя автоматически считать совместимыми. При несовпадении нужен согласованный кроссволк, а не переименование по названию.

`core.regions.region_id`: явные строковые коды CSV. `RU` и `FD-xx` — агрегаты; интерфейс списка субъектов по умолчанию их исключает. Все три модуля используют этот файл и одну версию классификатора. Общие темы заданы в topics.json.

Источники дедуплицируются по `normalized_identifier`: HTTPS, host lower-case без www, без fragment и завершающего `/`, query сохраняется. UUID v5 с namespace URL строится из этой строки, однако при существующем идентификаторе модуль использует UUID уже зарегистрированного источника. Общая платформа должна применять тот же алгоритм. Разные URL одного издателя не объединяются эвристически.

В автономном режиме миграция создаёт core, CLI seed добавляет отсутствующие строки без перезаписи справочников. В интегрированной БД установите `CORE_MANAGED_EXTERNALLY=true` **до применения миграции**: core уже должна существовать с совместимой структурой, темами и регионами. Миграция и seed не меняют общие справочники; регистрация собственных источников остаётся операцией с данными, а управление схемой передаётся платформе. Откат не удаляет core. Модуль владеет только схемой regional. Таблицы media/practices не создаются, внешних ключей на них нет.

## API

Все маршруты начинаются `/api/v1/`. OpenAPI: `/api/v1/openapi.json`; Swagger UI: `/api/v1/docs`.

- `/regions`, `/regions/{region_id}` — справочник и карточка.
- `/regional/indicators` — определения, единицы, направления, методология.
- `/regional/values` — фильтры region_id, indicator_code, year, history; limit 1–1000, offset.
- `/regional/profiles/{region_id}` — наблюдения региона, РФ и опубликованного ФО.
- `/regional/comparison` — повторяющийся параметр region_ids (2–5 уникальных), indicator_code, необязательный year.
- `/regional/data-quality` — ошибки, партии загрузки, дата последнего наблюдения; resolution_status, limit, offset.
- `/regional/deviations` — медиана субъектов и разности с РФ за год.
- `/regional/export` — CSV/XLSX, фильтры наблюдений, максимум 100000 строк.

Медиа и практики в будущем добавляются отдельными клиентами общей платформы по region_id и topic_id; этот модуль не загружает их данные. Наблюдения передают период, значение или NULL, единицу, источник, UTC-времена, статус и ревизию. JSON Decimal может передаваться строкой для сохранения точности. Даты ISO 8601. Стандартизированная ошибка: `{"error":{"code":"...","message":"...","details":[]}}`.

Совместимость: годовые наблюдения 2019+, текущая версия географии, без автоматической исторической гармонизации. Для новых полей общего контракта требуется согласование версий. Основные коллекции пагинируются; составные профиль и сравнение содержат все ряды выбранных регионов и предназначены для годовых данных компактного каталога.

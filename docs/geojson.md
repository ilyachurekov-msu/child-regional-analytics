# География: профиль 89 регионов

Профиль сверяется с набором владельца «Россия — геометрия регионов и учреждения»: https://datalens.ru/datasets/066oulh5srlmj-rossiya-geometriya-regionov-i-uchrezhdeniya . 24.11.2026 запрос одного поля «Регион» через временную несохраненную таблицу вернул 89 уникальных названий. Существующие датасет, подключения, чарты и дашборды не изменялись. В исходном native_map.csv отдельные части регионов записаны отдельными строками; количество строк не равно количеству регионов. Экспорт первой страницы содержал только 100 строк / 26 регионов и не считается полной выгрузкой. Оригинал остается в игнорируемом data/raw. Владелец не помнит источник геометрии, поэтому ее происхождение и право распространения не объявляются установленными.

Публикуемая геометрия имеет собственное проверяемое происхождение: geoBoundaries/OSM/Wambacher, release 9469f09, 2017 год представления границ. Используются 83 объекта RUS ADM1 (RUS-ADM1-28173009) и шесть объектов UKR ADM1 (UKR-ADM1-14850775). Для обоих наборов официальные метаданные подтверждают ODbL 1.0: https://www.geoboundaries.org/api/current/gbOpen/RUS/ADM1/ и https://www.geoboundaries.org/api/current/gbOpen/UKR/ADM1/ . Атрибуция и share-alike — data/GEOGRAPHY-LICENSE.md.

Сопоставление шести объектов: UA-43→RU-91, UA-40→RU-92, UA-14→RU-80, UA-09→RU-81, UA-65→RU-84, UA-23→RU-85. Префиксы shapeISO/shapeGroup в первоисточнике сохраняются; ключ region_id — прикладной crosswalk, а не изменение исходной ISO-классификации. RU-80/81/84/85 являются добавлением в кандидат общего справочника, с сохранением всех ранее существовавших ID; межмодульное принятие еще не подтверждено. Названия совпадают с 89-элементным профилем DataLens. Геометрии не редактировались, gzip — lossless; исходные и производные SHA записаны в data/geography-provenance.json, приложение проверяет SHA базовых 83 объектов, дополнения из шести объектов и собранной геометрии при чтении.

89 объектов покрывают весь выбранный профиль, но это исторические контуры 2017 года. Современная точность границ и наличие пяти лет статистики для каждого объекта этим не подтверждаются. Четыре добавленных ключа поддерживаются для годовых наблюдений с 2023-01-01; это ограничение статистического покрытия, не дата образования территории. Федеральный округ для них оставлен неизвестным.

Отображение — Plotly MapLibre с белым фоном без сетевых тайлов и ключей API. Нет данных — серый цвет; значения имеют отдельную шкалу и единицу. Есть выбор года, тултип и переход к паспорту выбранного региона. Браузерный тест ожидает загруженную карту с отрисованными объектами и сохраняет снимок за 2022 год. Географическое покрытие отделено от покрытия статистики; таблица наличия данных перечисляет все 89 регионов.

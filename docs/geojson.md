# География

Источник: geoBoundaries gbOpen RUS ADM1, boundaryID RUS-ADM1-28173009; release 9469f09. Официальные метаданные https://www.geoboundaries.org/api/current/gbOpen/RUS/ADM1/ получены 24 ноября 2026. Исходная база OpenStreetMap/Wambacher. Для этого конкретного набора лицензия **ODbL 1.0**, а не обобщенная CC-BY из обзора API. Атрибуция и условия — data/GEOGRAPHY-LICENSE.md.

Поле shapeISO сопоставлено с существующим цифровым region_id по проверенному crosswalk media. Таблица — contracts/geography-crosswalk.csv; геометрии не изменены, добавлен только region_id. Gzip с фиксированным mtime — lossless-хранение. Исходный и распакованный производный SHA — data/geography-provenance.json; приложение проверяет SHA при чтении.

Карта отображается через Plotly MapLibre с исходными GeoJSON-кольцами и белым фоном без сетевых тайлов или ключей API. Проверяются canvas и безопасный скриншот в CI; визуальная проверка обязательна, поскольку наличие слоя само по себе не подтверждает правильную географию. Исходные координаты, gzip и checksum не меняются.

83 уникальных объекта, 2017 год представления границ; RU-91/RU-92 из статистического справочника отсутствуют. Не объявляется полное современное территориальное покрытие. Субъекты с отсутствующими наблюдениями серые; числовые значения имеют отдельную шкалу и единицу измерения. Выбор года и переход к профилю поддержаны существующей картой Streamlit через событие выбора Plotly. Исследовательские тестовые значения не подменяют официальные наблюдения.

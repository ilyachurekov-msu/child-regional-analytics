# Проверка источников и ручная загрузка

Проверено 2026-11-24 в рамках разработки. Источник: Росстат, [«Естественное движение населения Российской Федерации»](https://rosstat.gov.ru/compendium/document/13269).

Страница публично доступна и описывает статистику ЗАГС о рождениях, смертях, браках и разводах. В HTML действительно обнаружены относительные ссылки:

- `/storage/mediabank/EDN_2023.xlsx` — на странице указана дата 12.07.2024.
- `/storage/mediabank/EDN_2022.xlsx`.
- `/storage/mediabank/EDN_2021.xlsx`.

Запросы к файлам возвращали 403/404, в том числе через хост www. Подтверждённая страница не гарантирует доступность файла. Файл `Region_Pokaz_2025.pdf`, обнаруженный поиском на официальном домене, также вернул 404. Структура этих файлов не была просмотрена; реальные наблюдения не извлечены. В окружении выявлена проблема доверия корневому TLS-сертификату; для разовой диагностики открытых страниц проверка TLS отключалась. В коде загрузчика TLS всегда проверяется. Для корпоративного прокси задайте доверенный сертификат стандартными средствами окружения; не отключайте TLS в эксплуатации.

Официальные страницы могут менять ссылки. `scripts.fetch_rosstat` обнаруживает ссылки на странице, проверяет HTTP и ZIP-сигнатуру XLSX, сохраняет исходник и журнал. Это загрузчик исходных файлов, не непроверенный парсер таблиц. JSON поддерживается для локального нормализованного обмена; существование JSON API Росстата не заявляется. ЕМИСС и ведомственные API пока не подключены.

## Условия использования

Работа ограничена общедоступной агрегированной статистикой; сохраняйте название Росстата, адрес публикации, период, единицу и примечания. Точная лицензия на найденной странице не подтверждена: перед массовым распространением исходных публикаций проверьте условия Росстата. Ограниченный последовательный загрузчик использует паузу между запросами; капча и ограничения доступа не обходятся.

## Ручной порядок

1. Откройте официальную страницу, выберите год и скачайте XLSX доступным способом. Сохраните исходник в `data/raw/`.
2. Проверьте заголовки, единицы, территориальный охват и сноски. Для каждого ряда должны совпадать определения; не смешивайте коэффициенты на 1000 жителей с абсолютными числами.
3. Перенесите только проверенные таблицы в нормализованный шаблон `contracts/import_template.csv`. Для начала используйте пять показателей из `contracts/indicators.json`. Не ставьте дату загрузки вместо неизвестной даты публикации.
4. Исключите строки итогов, если нет однозначного кода `RU`/`FD-xx`. Разделяйте территории, включающие и исключающие автономные округа. Неизвестные названия оставьте для ручного разбора.
5. Сохраните рядом описание преобразования и ссылки. Выполните `scripts.import_data` по README. Проверьте раздел качества и число строк.
6. Повторите импорт: номер партии должен сохраниться. Исправленная публикация с иной контрольной суммой создаёт новые ревизии изменившихся наблюдений.

Для завершения MVP нужны реальные значения пяти сопоставимых показателей хотя бы двух субъектов минимум за два года. До получения исходников приложение показывает пустую базу, а не демонстрационную статистику.

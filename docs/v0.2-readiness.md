Оригинал Кемеровостата имеет SHA b3d8aba8e051d2ed98878258c950356f7b16d8680b73e1ff184452cac47078b3; добавленные значения 2018: births 26540, deaths 38748, natural_change −12208, marriages 15963, divorces 11556. ## Реализация

Карта: получены и сопоставлены 89 геометрий, ODbL, исторические границы 2017 года; состав сверяется с DataLens владельца. Геометрия DataLens неизвестного происхождения не распространяется. Исходные shapeISO/shapeGroup сохранены, прикладной crosswalk описан в docs/geojson.md. Все геометрии проходят SHA/crosswalk проверку. Увеличение охвата статистики остается отдельной задачей.

Контракты: существующие цифровые region/topic IDs сохранены; canonical source-профиль media перенесен в пакет через aliases, старые UUID не заменялись. Practices read-only запрос — 404; согласование трех владельцев не подтверждено. Migration0003 создаёт только regional.source_aliases.

Migration0004 расширяет поддерживаемое временное покрытие RU-42 до 2018-01-01 для проверенного полного года. Существующие ключи и наблюдения не переписываются. При внешнем управлении core изменение не применяется; при откате требуется сначала согласовать наблюдения 2018 года. Проблема межплатформенных переводов строк исправлена: normalized SHA считается по LF, отдельный тест проверяет фактический импорт всех 25 строк и повторяемость.

Обновление: dry-run, сравнение SHA/версий адаптера, отчеты запусков, откат ошибок до commit, необязательный отключенный локальный scheduler. Нет платной инфраструктуры, deployment или использования Actions как постоянной БД.

## Проверки

Локально пройдены 36 unit/API/UI/ETL тестов, Ruff и проверка shared-contracts. Обязательная приемка CI включает PostgreSQL16+pgvector (8 тестов), миграции 0001–0005, Docker init/API/Streamlit, браузерный сценарий семи страниц со снимком карты за 2022 год и проверкой отрисованных объектов, сохранность 46 наблюдений после рестарта (26 официальных + 20 явно синтетических CI-фикстур), аудит зависимостей и Gitleaks. Актуальный результат для конкретного commit и артефакты находятся во вкладке Checks PR2; прежние прогоны карты 83 регионов не заменяют приемку профиля 89. Реальные и тестовые наблюдения не смешиваются в подсчете официального покрытия. Проверка исходной выборки 20 строк сохранена для регрессий.

Migration0005 добавляет четыре новых прикладных ID с началом годового покрытия 2023-01-01 и неизвестным ФО, сохраняет прежние ключи и данные, останавливается при коллизии названий. При внешнем управлении core изменение не применяется. Downgrade не удаляет справочные ID. Контракт 1.1.0 — аддитивный кандидат, PLATFORM_AGREED=false.

API качества и Streamlit перечисляют все 89 регионов с количеством наблюдений, периодов, показателей и фактическими границами периода. Нулевое значение учитывается; NULL исключается. Ни карта, ни таблица покрытия не создают отсутствующие статистические значения. Сетевой клиент выполняет условные запросы, ограничивает размер/частоту и сохраняет паузу хоста после 403/429/503; повторные запросы не обходят отказ.

PR: https://github.com/ilyachurekov-msu/child-regional-analytics/pull/2 , отдельно от PR1, с базой codex/mvp-acceptance. Merge и релиз не выполнялись. Соседние репозитории проверялись только read-only.

Открытые обязательные критерии: все доступные реальные регионы за пять лет (минимум 10 пока не получен); подтвержденные опубликованные РФ/ФО; реальное межрегиональное сравнение и метрики покрытия; окончательное согласование платформенного контракта. До их закрытия результат — частичная реализация v0.2.0 с честно обозначенным неполным покрытием.

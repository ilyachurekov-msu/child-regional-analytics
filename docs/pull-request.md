# Техническая приёмка региональной аналитики v0.1.0

Исходная версия имела 12 локальных тестов без исполненных PostgreSQL/Docker проверок и без реальных наблюдений. Эта ветка исправляет контроль форматов, единиц, ревизий и дат, сохраняет происхождение оригиналов и добавляет обязательные PostgreSQL 16, Docker и браузерные проверки в GitHub Actions. Тесты PR не обращаются к Росстату.

Подключён полученный официальный HTML-сборник Кемеровостата: 20 проверенных наблюдений пяти показателей за 2019–2022 годы (Кузбасс), точные таблицы 4.12/4.20, единицы, сверка естественной убыли, SHA-256 исходника и нормализованной выборки. В Git включён только числовой поднабор с атрибуцией; автоматический offline импорт при запуске не зависит от сайта. Недоступные источники журналируются. Кандидат shared-contracts сохраняет существующие ID; несовпадения с media и отсутствие practices явно отмечены, согласование не заявлено.

Проверено локально: 18 unit/API/UI/ETL тестов, Ruff, целостность пакета контракта, генерация SQL миграций 0001/0002. Отдельные 6 PostgreSQL интеграционных случаев и браузерный тест должны исполниться в CI; локальный SQLite не считается их заменой. Официальных наблюдений пока 0, подтверждённого GeoJSON нет; MVP не объявляется готовым. Полный аудит и критерии — docs/mvp-audit.md и docs/mvp-readiness.md.

Автоматического merge, релиза, платной инфраструктуры и публичного сервера нет.

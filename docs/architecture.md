# Архитектура и план

Версия приложения 0.1.0; контракт 1.0.0. Единственный репозиторий и папка сохраняются при всех исправлениях.

Слои: Streamlit → FastAPI `/api/v1/` → сервисы анализа / SQLAlchemy → PostgreSQL 16. Отдельные CLI получения и импорта данных работают через тот же слой моделей. UI читает API, экспортирует полученные наблюдения. Другие модули не реализуются.

1. Требования и архитектура — описаны.
2. Репозиторий и Docker Compose — подготовлены; проверка Docker ещё требуется.
3. Схемы `core`, `regional` — модели и миграция 0001, неизменяемый снимок метаданных.
4. Справочники и импорт — версионируемые seeds, нормализация, архив SHA-256, журнал ошибок.
5. Первый источник — подтверждена страница Росстата; файлы оказались недоступны. Автоматическая нормализация исходного бюллетеня не реализована без проверки его структуры.
6. API — чтение справочников и наблюдений, профиль, сравнение, качество, отклонения, экспорт.
7. UI — семь разделов с обработкой пустой базы.
8. Аналитика — временные ряды, абсолютные и относительные изменения, медиана, прозрачный конструктор индекса min-max.
9. Экспорт — CSV, XLSX, краткая справка Markdown.
10. Проверки — тесты импортов и API; актуальные результаты в report.md.

## Целостность

UUID наблюдений сохраняются в БД; UUID источника детерминирован по нормализованному URL. `normalized_identifier` уникален. Показатели имеют стабильные UUID из seed-файла. Идентификаторы регионов заданы явно в CSV, не вычисляются из названия. Регионы-агрегаты: `RU`, `FD-01`…`FD-08`; субъекты: `RU-xx`.

Естественный ключ наблюдения: показатель + регион + начало + конец периода. Ревизии нумеруются внутри этого ключа. Частичный уникальный индекс допускает только одну текущую версию. PostgreSQL advisory lock сериализует импорты, включая регистрацию источника. Транзакция охватывает весь импорт; некорректные строки журналируются и пропускаются. Сбой БД откатывает транзакцию. Файловый архив может содержать файл откатившейся загрузки, он не является признаком завершённого импорта.

Изменение алгоритма сопоставления требует повышения `PARSER_VERSION`, после чего файл можно пересчитать без стирания предыдущих загрузок. Витрины вычисляются запросами над `is_current`, отдельных денормализованных витрин пока нет.

## Методологические границы

Отдельные темы детства, образования и поддержки пока не имеют проверенных наблюдений. Общедемографические абсолютные числа не объявляются прямой оценкой благополучия детей. Производные коэффициенты не рассчитываются без согласованного знаменателя. Суммы субъектов не используются вместо РФ/ФО, в том числе из-за вложенности автономных округов. Конструктор индекса требует явных направлений и положительных весов; при пропуске хотя бы одной компоненты индекс региона отсутствует. При одинаковых значениях нормирование отклоняется.

Справочник отражает географическую базу на 2018-11-03: 85 субъектов в классификации соответствующих таблиц Росстата; позднейшие изменения не добавляются без проверки совместимости и даты действия. ОКАТО/ОКТМО пока NULL. Названия Архангельской и Тюменской областей требуют проверки охвата таблицы (включение автономных округов). Исключающие округа варианты не сопоставляются автоматически. Нужна отдельная историческая версия для данных до 2019 года.

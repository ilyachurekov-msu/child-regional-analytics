## Карточки и автоматизация

`contracts/indicator-metadata.json` содержит определения, единицы, источник, покрытие и ограничения. `/api/v1/regional/indicator-metadata` дополняет карточки фактическим числом наблюдений и последней загрузкой из текущей БД. Источники/адаптеры — `data/source-manifest.json`; контролируемое обновление сохраняет оригинал, checksum, нормализацию и отчёт. Регулярное расписание не включено. PR-проверки используют зафиксированный числовой поднабор и не скачивают Росстат из сети.

## Незакрытые критерии

1. **Несколько регионов:** подтверждён только RU-42. Сравнение 2–5 регионов проверено отдельными искусственными тестовыми рядами; сравнение двух реальных регионов не объявляется выполненным. Другие официальные публикации в журнале отвечали 403/404 или тайм-аутом. Значения чужих территорий не подставлялись.
2. **Общие контракты:** пакет-кандидат shared-contracts 1.0.0 подготовлен и проверен по SHA, но media использует другие ID регионов и другой namespace источников. practices недоступен для сравнения. ID не заменялись; согласование всех трёх модулей не подтверждено.
3. **Карта:** проверенный GeoJSON с происхождением, лицензией, версией и полным покрытием не получен. Сохранён табличный режим; критерий карты открыт.
4. **РФ/ФО:** сопоставимых опубликованных абсолютных агрегатов в текущем наборе нет, интерфейс показывает отсутствие, не вычисляет простое среднее.

Следующий этап: подключить второй официальный регион по тем же пяти определениям, согласовать кроссволк общих справочников с обоими модулями и проверить лицензированные географические границы. До этого PR остаётся draft, MVP не объявляется полностью готовым.

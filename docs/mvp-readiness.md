## Что закрыто кодом

Исправлено принятие старой публикации с тем же числом; неизвестная дата теперь NULL. Добавлены проверки единиц, статуса missing и строгих дат, ранний отказ при смене обязательных столбцов. История оригинальных публикаций учитывает SHA исходника, даже если нормализованные числа не изменились. Пакет общего контракта проверяется по контрольным суммам и не подменяет конфликтующие ID.

## Что блокирует завершение

1. Получение оригинальных официальных файлов, проверка адаптера и фактический импорт пяти показателей в рабочую PostgreSQL. Территориальные сайты в текущей среде отвечают тайм-аутом; центральные XLSX — 403/404. Поисковые сниппеты не подменяют файл.
2. Авторизованная отправка кода в новый GitHub. Browser создал репозиторий, GitHub integration возвращает Resource not accessible by integration при записи; первый вход Git отменён. Повторный стандартный вход Git ожидается от пользователя. Секреты и пароли не запрашиваются в чате.
3. Успешные Actions (PostgreSQL, Docker, браузер, безопасность) с сохранёнными артефактами и ссылка на PR. Наличие YAML не равняется успешному исполнению.
4. Согласование единого справочника всех трёх модулей. Географическая карта отдельно остаётся незакрытым критерием.

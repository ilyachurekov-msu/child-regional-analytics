# Отчёт о реализации — 24 ноября 2026

## Реализовано

Один исходный проект в текущей рабочей папке; структура соответствует ТЗ. Backend FastAPI и Streamlit, PostgreSQL 16/pgvector в Compose, SQLAlchemy, Alembic, конфигурация Pydantic. Общие схемы core и regional, никаких таблиц media/practices. Стабильные CSV-идентификаторы регионов, восемь тем, пять описанных демографических/семейных показателей; общий контракт 1.0.0 и снимок OpenAPI.

Импорт нормализованных CSV/XLSX/JSON: архивирование по SHA-256, контроль формата/типов/периодов/названий, пропуски, очередь неизвестных регионов, история изменений и защита текущего наблюдения уникальным индексом, сериализация импорта в PostgreSQL. CLI загрузки исходных файлов обнаруживает ссылки на официальной странице, не выдумывая API.

API справочников, показателей, наблюдений, профилей, сравнения 2–5 регионов, качества, отклонений и экспорта; пагинация основных коллекций, фильтры, валидация, стандартные ошибки. Профили отображают опубликованные РФ/ФО при их наличии. Семь русскоязычных разделов Streamlit, линейные графики, таблицы, исследовательский конструктор индекса с явными весами и направлениями, выгрузки CSV/XLSX и справки Markdown. Карта подготовлена к подключению локального GeoJSON; отсутствующие значения серые.

## Проверки и результат

Итоговый прогон: **12 тестов пройдено за 4,85 секунды**. Проверены все семь страниц Streamlit с пустой базой и с временными искусственными наблюдениями, включая графики Москвы и сравнение с Санкт-Петербургом; форматы CSV/XLSX/JSON, ревизии, дедупликация, пропуски, некорректные значения, API и экспорт. Эти наблюдения создаются исключительно в тестовых временных файлах и БД. SQL миграции успешно сгенерирован для PostgreSQL без подключения к серверу (`docs/schema.sql`); Ruff: `All checks passed`. Один warning зависимостей Starlette о будущем клиенте httpx2. SQLite используется только в тестах. Полноценная браузерная визуальная проверка и выполнение на PostgreSQL ещё не проведены.

## Невыполненные критерии MVP

1. **Реальные наблюдения пяти показателей не загружены.** Официальная страница Росстата проверена, но ссылки на файлы возвращают 403/404. Файлы и структура не просмотрены; парсер оригинальных бюллетеней нельзя честно считать реализованным. Существует рабочий нормализованный импорт и инструкция ручного получения/подготовки. Ни одна тестовая цифра не подставлена в рабочую базу.
2. **Docker Compose и PostgreSQL ещё не запущены:** Docker Desktop не установлен/не обнаружен в среде. Нужны интеграционные проверки миграций, параллельного импорта и UTC на PostgreSQL 16.
3. **Полноценная карта требует GeoJSON:** исходные географические границы и их лицензия пока не проверены. Интерфейс явно сообщает об отсутствии файла.
4. Образование, здравоохранение, семейное устройство и социальная поддержка не включены до проверки методологии и данных. Каталог сейчас содержит общедемографические показатели, не прямую оценку положения детей.

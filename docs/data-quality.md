# Контроль качества и пересмотры

Адаптер `kemerovo-yearbook-html/1.0.0` проверен на реально скачанном оригинале. Он принимает только Windows-1251, точные заголовки таблиц, пять лет исходного блока и заданное покрытие 2019–2022, проверяет границу абсолютных чисел и коэффициентов, исключает городское/сельское население и справочные коэффициенты РФ. Импорт офлайн-поднабора проверяет его SHA-256 по provenance; повторный запуск не создаёт наблюдения заново. При непредвиденной структуре оригинала загрузка прекращается.

Импорт не заменяет NULL нулём. `missing` означает отсутствие значения, `provisional` — предварительную публикацию, `official` — опубликованные сведения с подтверждённым статусом. Нулевая величина — отдельное действительное наблюдение. Отсутствие публикационной даты хранится NULL, а не датой загрузки. Timestamp с известным временем приводится к UTC; если известна лишь календарная дата публикации, UTC midnight — условное представление даты с указанием точности в manifest.

Проверяются числовая точность NUMERIC(24,6), конечность числа, допустимость отрицательных величин, полный год, даты действия территории, известные коды показателей и однозначные регионы. При наличии поля unit оно должно точно соответствовать каталогу. Смена единицы требует отдельной методологии и показателя, автоматического пересчёта нет. Модель пока не хранит интервалы несопоставимости: такие ряды нельзя объединять без внешней проверенной процедуры.

Одинаковый SHA-256 + источник + версия парсера возвращает существующую партию. Изменение значения создаёт новую ревизию; уникальный частичный индекс допускает ровно одну текущую версию естественного ключа. Более старая публикация отклоняется. Транзакционный advisory lock PostgreSQL сериализует импорты; это отдельно тестируется на настоящей PostgreSQL. Исправление aliases или алгоритма требует новой версии парсера.

Нормализованный файл архивируется по SHA-256. Специализированный конвейер дополнительно архивирует оригинал, записывает `original_checksum`, `original_path`, версию адаптера, отчёт и время последней успешной загрузки. Распространять исходники без ясных условий нельзя; архив игнорируется Git. Проблемы формата и сопоставления видны в разделе качества. Корректные строки частичной партии сохраняются; ошибки не считаются успешным полным обновлением.

PDF-адаптер Липецкстата проверяет регион, единицы, годы, названия пяти строк, отсутствие дублей и тождество `births - deaths = natural_change`. Изменение структуры приводит к ошибке до записи наблюдений. Пока оригинал недоступен, адаптер выключен в manifest. Для проверки используйте `--validate-only`; импорт после проверки требует явного `--approve-adapter`. Регулярный запуск не активирован.

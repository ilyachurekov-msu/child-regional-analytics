## Подтверждённый источник: Кемеровостат

Официальный [раздел 4 сборника «Кузбасс»](https://service.kemerovostat.gks.ru/bgd/EJEGOD/issWWW.exe/Stg/2022/4.%20%D0%BD%D0%B0%D1%81%D0%B5%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5.htm) успешно скачан напрямую 24.11.2026. SHA-256 исходника `b3d8aba8e051d2ed98878258c950356f7b16d8680b73e1ff184452cac47078b3`. Проверены таблица 4.12 (всё население, абсолютные рождения/смерти/естественный прирост) и 4.20 (абсолютные браки/разводы до строк коэффициентов). Извлечены 20 наблюдений пяти показателей за 2019–2022 годы, регион RU-42. По всем годам сверено тождество рождения − смерти = естественный прирост.

Методологические пояснения самого сборника подтверждают годовую разработку актов ЗАГС и учёт только живорождений. Переписной пересчёт знаменателей влияет на коэффициенты; коэффициенты и справочные показатели России в абсолютную витрину не импортируются. Дата публикации неизвестна: дата сохранения Word не используется вместо неё. В Git включены только числовые факты и атрибуция, оригинал остаётся в игнорируемом архиве. `data/official/provenance.json` фиксирует происхождение, SHA исходника и нормализованной выборки. Offline импорт: `python -m scripts.load_official_bundle`; live проверка: `python -m scripts.update_data --source kemerovo-yearbook-2022 --validate-only`.

Числа в поисковом индексе не объявляются полученным исходным файлом. На основании одних сниппетов рабочие наблюдения не создавались. Точный результат повторного получения фиксируется в data/archive/latest-update-report.json; исходники и архив не попадают в публичный Git.

Manifest доступных адаптеров: data/source-manifest.json. Липецкий PDF-адаптер реализован, но выключен до сверки оригинала и результатов. Исходник сохраняется в оригинальном PDF-формате, отдельный нормализованный JSON — в архиве; оба получают контрольные суммы. Пока проверка только на искусственном макете таблицы, последняя успешная реальная загрузка NULL. Специально не реализуется универсальный парсер неподтверждённых таблиц.

Для управляемой проверки: `python -m scripts.update_data --source lipetsk-edn-2023 --validate-only`. После успешного получения и ручной сверки результата с таблицей: тот же вызов с `--approve-adapter` вместо `--validate-only` при настроенной PostgreSQL. При законно полученном оригинале допускается `--file path/to/original.pdf`. От пользователя не требуется вручную собирать нормализованные таблицы.

ЕМИСС остаётся кандидатом: проверенный endpoint автоматической выгрузки не установлен; адреса API не выдумываются. В исходном MVP проверенного GeoJSON не было; в кандидате v0.2 получены 89 геометрий geoBoundaries с ODbL и provenance (см. docs/geojson.md). Административные коды не считаются географией и не заменяются геометриями с похожими названиями.

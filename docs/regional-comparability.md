# Сопоставимость

В рабочей официальной выборке пять абсолютных годовых показателей: births, deaths, natural_change (человек), marriages, divorces (единиц). Территория — всё население Кемеровской области — Кузбасса, RU-42. Годы 2018–2022. Городские/сельские подгруппы и коэффициенты на 1000 населения исключены. Для каждого года births − deaths = natural_change. Пропуски не интерполируются. Не смешиваются прогнозы, квартальные значения и годовая статистическая разработка.

API сравнения принимает субъекты, РФ (RU) и ФО (FD-*). Показатели России и округа возвращаются только из опубликованных наблюдений, а не из среднего по субъектам. Отклонение от ФО вычисляется по его опубликованной строке с совпадающим federal_district; при ее отсутствии — NULL. В текущей официальной выборке таких агрегатов нет. Тестовые агрегаты проверяют формулы и не импортируются как реальные.

Абсолютный ранг зависит от размера населения и не измеряет благополучие. Медиана строится только по субъектам, исключает RU и FD-*. Межрегиональные реальные выводы пока невозможны: подтвержден один регион. Общая методология ЗАГС не гарантирует отсутствия различий учета/пересмотра в будущих источниках; перед подключением каждого издания проверяются сноски и статус official/provisional. Переписные пересчеты знаменателей особенно важны для коэффициентов, не входящих в эту выборку.

Границы карты представлены по источнику 2017 года и не утверждают соответствие всем современным изменениям. RU-91 и RU-92 не покрыты геометрией. Архангельская/Тюменская области и автономные округа требуют контроля включения/исключения при будущих федеральных таблицах; суммы без такой проверки запрещены.


Профиль 89 сохраняет 85 исходных идентификаторов и добавляет четыре прикладных ключа без назначения неизвестного ФО. Наличие исторической геометрии не разрешает переносить годовые наблюдения на другой территориальный состав. Отдельный оперативный итог РФ births за 2024 (1 222 408, Росстат 21.02.2025) не используется вместо отсутствующих итогов 2018–2022 и не заполняет пробелы регионов. Пресс-релиз не раскрывает подробный территориальный охват; полноценное сопоставление этого итога с региональными рядами требует дополнительных методологических сведений.
